# Contributing

Thanks for your interest in Presensi School.

## How to contribute
1. Fork the repo
2. Create a feature branch: `git checkout -b feat/my-feature`
3. Make changes and add tests where possible
4. Run checks: `php -l` on changed PHP files; `pytest tests/` in agent repo
5. Commit with clear messages
6. Open a Pull Request

## Code style
- Follow existing PHP/TS/Python style
- Do not commit `.env` or secrets
- Keep changes focused and small

## Reporting issues
Open an issue with steps to reproduce and expected behavior.
